# Decision records

## 001 Local Spark, optional Free Edition

Spark runs inside the pipeline image because the Windows host has no JVM. Parquet is the portable lake format. Delta is written beside it and again on Databricks Free Edition. A commercial Databricks trial is not part of the setup, because attaching a cloud account can create a bill.

## 002 Public snapshot instead of a hosted API

Free application hosts sleep, expire, or ask for a card. The console therefore reads an aggregate snapshot. Scenario sliders snap to results the Python solver already computed, so the browser does not carry a second optimizer.

## 003 Daily arrivals, one holdout

The modeled target is daily eligible arrivals by service line, horizon 14 days. The next 24 hours on the overview are a seasonal naive hourly view, labeled as such. Model choice uses the validation window only. Test metrics are written after that choice.
